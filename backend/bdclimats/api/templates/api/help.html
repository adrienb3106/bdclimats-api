BDClimats API - Aide

Points d'entree principaux :

  • /api/ : racine DRF (liste les endpoints)
  • /api/indicators/ : CRUD Indicators
  • /api/datasets/ : CRUD Datasets (a venir)
  • /api/computation-rules/ : CRUD ComputationRules (a venir)

Exemple POST Indicator

{
  "dataset": 1,
  "code": "T2M_MEAN",
  "name": "Temperature moyenne 2m",
  "unit": "C"
}

Astuce : l'API root /api/ est generee par DRF DefaultRouter.
